## Ход работы
1. Развертывание виртуального окружения (venv):
```bash
python -m venv venv
```
2. Активация venv:
```bash
venv/Scripts/Activate.ps1
```
3. Устанавливаем mkdocs:
```bash
pip install mkdocs
```
4. Сохраняем зависимости в requirements.txt:
```bash
pip freeze > requirements.txt
```
5. Настраиваем развёртывание с помощью GitHub Actions. Все действия описаны в `deploy.yml`, внутри которого настроены шаги по настройке окружения, установкой зависимостей для mkdocs, генерацией статических файлов и непосредственно публикацией на GitHub Pages.
6. В итоге получили сайт, который можно увидеть [тут]().

### Возможности Gitverse для реализации CI/CD
В настоящее время все чаще используют Gitverse как альтернативу GitHub/GitLab. Этот сервис предоставляет следующие возможности:
1. Автоматизация сборки и тестирования
2. Контейнеризация и оркестрация
3. Интеграция с отечественными инструментами (Яндекс.Облако, SberCloud, VK Cloud и т.д.)
4. Поддержка всех российских стандартов безопасности

### Какие существуют варианты деплоя статического сайта в продакшен среду и какие технические инструменты для этого могут потребоваться, приведите примеры
1. Для простых сайтов: облачные хранилища + CDN
